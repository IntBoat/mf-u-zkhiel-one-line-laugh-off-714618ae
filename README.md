# One-Line Laugh-Off

A make.fun one-line entry: exactly one funny line. The program in `main.py` writes the entry text to `/output/entry.txt`, where the competition's sealed scorer reads it.

Competition: https://make.fun/api/competitions/u-zkhiel-one-line-laugh-off-714618ae/requirements

## Entry

My smart fridge just emailed me a diet plan, which is rich coming from an appliance that has never once closed its own door.
